# The ultimate unit converter

Because americans will use anything but the metric system.

## Usage

Assuming you have Go 1.25+ installed, clone the repo, `cd` into it and run `make serve` (or bare `make`) to build the server and launch it in the foreground. The app should then be reachable from your browser at `127.0.0.1:9393`.
